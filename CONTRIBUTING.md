# Contribuer à Markdown2Gmail

Les contributions sont les bienvenues : signalement de bug, idée, correction.

## Comment contribuer

- Ouvrir une issue pour décrire le problème ou la proposition
- Ou proposer une pull request, de préférence liée à une issue
- Une modification par pull request, avec une description claire

En soumettant une contribution, vous acceptez :

- qu'elle soit diffusée sous la licence du projet ;

Vous restez auteur de votre contribution.
